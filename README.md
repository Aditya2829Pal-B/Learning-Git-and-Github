# Git & GitHub Learning Repository

This repository is created as a personal learning space to explore and practice **Git commands** and understand the **workflow of GitHub**. It serves as a hands‑on guide to version control, collaboration, and project management using Git and GitHub.

## Objectives
- Learn and apply essential Git commands:
  - `git init`, `git clone`, `git add`, `git commit`
  - `git push`, `git pull`, `git status`, `git log`
- Understand branching and merging:
  - Creating branches
  - Switching between branches
  - Resolving merge conflicts
- Explore GitHub features:
  - Creating repositories
  - Managing issues and pull requests
  - Collaborating with contributors
  - Using GitHub Actions for automation

## Why This Repo?
Version control is a critical skill for developers. By practicing here, I aim to:
- Build confidence in using Git for real projects
- Learn collaborative workflows used in open‑source and industry
- Prepare for internships and professional development

## Structure
- **Examples/** → Contains small demo projects to test commands  
- **Notes/** → Step‑by‑step explanations of commands and workflows  
- **Exercises/** → Practical tasks to reinforce learning  

## Roadmap
1. **Day 1–2:** Git basics (init, clone, commit, push)  
2. **Day 3–4:** Branching, merging, conflict resolution  
3. **Day 5–6:** GitHub collaboration (forks, pull requests, issues)  
4. **Day 7+:** Advanced topics (rebasing, stash, GitHub Actions)

---

This repository is not about building a final product but about **learning by doing**. Every commit, branch, and pull request here is part of the journey to mastering Git and GitHub.
